### Exercițiul 1 - Verificarea frecvenței critice Nyquist (fs = 20 Hz, f_Nyquist = 10 Hz)

| f_semnal (Generator) | Condiție raportată la f_Nyquist | Frecvență aparentă în Serial Plotter |
| :---: | :---: | :---: |
| **5 Hz** | `f_semnal < f_Nyquist` | **5 Hz** |
| **10 Hz** | `f_semnal = f_Nyquist` | **10 Hz** |
| **15 Hz** | `f_semnal > f_Nyquist` | **5 Hz** |
| **20 Hz** | `f_semnal = fs` | **0 Hz** |
